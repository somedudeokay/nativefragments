# Create Native Fragments App

Scaffold a fast, explicit HTML application for Cloudflare Workers.

```sh
npm create @nativefragments/app@latest my-app
cd my-app
npm install
npm run dev
```

The generated app includes streamed server routes, the explicit browser router,
Lit SSR and hydration, API routes, native form actions, esbuild, and Wrangler.
Development and deployment are separate commands.
